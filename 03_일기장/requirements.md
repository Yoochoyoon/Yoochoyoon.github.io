# 일기장 앱 개발 지침

## 제약사항
1. 리액트, 뷰와 같은 프레임워크는 사용금지
2. index.html 파일 하나에 자바스크립트, html, css 넣기
3. nodejs, 엔진엑스등 웹서버 설치금지
4. 별도의 설치형 데이터베이스와 sqlite 사용금지
5. 데이터베이스는 웹브라우저용 데이터베이스 사용

## 기능 요구사항
6. 일기 저장, 일기 수정, 일기 삭제 가능한 일기장 앱 만들기

## 실행 방식
7. 실행은 index.html 파일 하나만 더블클릭해서 웹브라우저에서 실행

## 마무리
8. 작업 후 claude.md 파일을 생성 또는 업데이트
