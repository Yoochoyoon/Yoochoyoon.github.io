# 유초윤포트폴리오

웹 개발과 게임 & 디자인 분야의 프로젝트 경험을 보여주는 GitHub Pages 포트폴리오입니다.

## 소개

이 포트폴리오는 다음 분야의 프로젝트들을 선보입니다:

- **웹 개발**: React, Node.js, 데이터베이스 등을 활용한 풀스택 웹 애플리케이션
- **게임 & 디자인**: 게임 개발, UI/UX 디자인, 그래픽 디자인 작업

## 구조

- `index.html` - 메인 포트폴리오 페이지
- `docs/` - 포트폴리오 기획 및 설계 문서
- `css/` - 스타일시트
- `js/` - 자바스크립트 로직
- `assets/` - 이미지 및 리소스 파일

## 특징

- 반응형 디자인으로 모든 기기에서 최적화
- 다양한 프로젝트 카드와 상세 정보 표시
- 기술 스택 및 역량 소개
- 연락처 및 소셜 미디어 링크

## 배포

이 프로젝트는 GitHub Pages를 통해 배포됩니다.
