# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 언어 사용 지침

- 이 프로젝트에서 작업할 때는 가급적 한글을 사용해서 대화할 것.

## 폴더 목적

- 이 폴더는 코드 저장소가 아니라, 사용자의 **이력서와 자기소개서를 관리하기 위한 폴더**입니다.
- 사용자와의 대화를 통해 이력서·자기소개서 작성에 필요한 정보를 이끌어내고, 이를 바탕으로 문서를 함께 관리합니다.
- 필요한 파일(이력서, 자기소개서, 포트폴리오 자료 등)이 아직 없다면, 어떤 파일이 필요한지 사용자에게 먼저 물어볼 것.
- 정보가 부족하면 선택지를 주는 방식보다, 자연스러운 대화로 사용자를 인터뷰하듯 질문하여 최대한 정보를 이끌어낼 것. 이끌어낸 정보는 `마스터_프로필.md`에 계속 반영한다.

## 주요 파일

- `마스터_프로필.md`: 이력서·자기소개서 작성의 기반이 되는 개인 정보 저장소. 학력, 목표, 경력/활동 이력, 스킬, 자격증, 링크, 강점 등을 정리해두고, 새로운 정보가 생기면 계속 업데이트한다.
- `채용정보_잡코리아.md`: 마스터 프로필의 희망 직무를 기준으로 수집한 채용공고 목록. 지원 여부를 체크박스로 관리하며, 새 공고를 찾을 때마다 계속 추가한다.
- `채용정보_해외인턴십_일본.md`: 일본 해외 인턴십 관련 조사 자료. 국내 일본계기업 인턴십, K-Move 스쿨, 후쿠오카 게임 인턴십 등 경로별로 정리.
- `역량개발_로드맵.md`: 희망 직무별로 필요한 역량과 현재 갭을 정리한 개발 계획. 체크박스로 진행 상황을 관리한다.
