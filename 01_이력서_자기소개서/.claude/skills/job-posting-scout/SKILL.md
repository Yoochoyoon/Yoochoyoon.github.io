# 채용공고 리서치 스킬

`마스터_프로필.md`의 희망 직무를 기준으로 여러 채용 플랫폼에서 공고를 찾아 `채용정보_잡코리아.md`에 정리하는 스킬입니다. 파일 이름은 처음 잡코리아만 다루던 시절의 이름이 그대로 남은 것이고, 지금은 여러 플랫폼을 함께 다루는 통합 리스트로 씁니다 — 굳이 파일명을 바꾸거나 플랫폼별로 파일을 쪼갤 필요는 없습니다.

## 왜 이런 구조로 관리하는가

채용공고는 금방 사라지고 바뀝니다. 매번 처음부터 검색하면 이미 확인했던 공고를 또 찾거나, 지원 여부를 까먹기 쉽습니다. 그래서 이 폴더는 "한 번 찾은 공고는 파일에 누적하고, 지원 상태를 체크박스로 계속 추적"하는 방식을 씁니다. 이 스킬의 역할은 새로 검색해서 찾은 결과를 이 누적 구조에 자연스럽게 얹는 것이지, 매번 파일을 새로 쓰는 것이 아닙니다.

## 진행 순서

### 1단계 — 검색 기준 파악

`마스터_프로필.md`의 "목표" 섹션에서 희망 직무와 우선순위를 확인합니다 (게임 클라이언트/서버, 게임 프론트엔드, 웹 프론트엔드 등). `채용정보_잡코리아.md` 상단의 "검색 키워드" 목록도 참고하되, 사용자가 이번에 특정 키워드나 회사를 지정했다면 그것을 우선합니다.

`채용정보_잡코리아.md`를 먼저 읽고 이미 등록된 공고(링크 기준)를 파악해두세요 — 같은 공고를 중복으로 추가하지 않기 위함입니다.

### 2단계 — 플랫폼별 검색

기본적으로 아래 플랫폼을 대상으로 합니다. 사용자가 특정 플랫폼만 지정하면 그것만 검색하세요.
- 잡코리아 (JobKorea)
- 원티드 (Wanted)
- 사람인 (Saramin)
- 게임잡 (GameJob) — 게임업계 전문 플랫폼이라 다른 곳엔 없는 공고가 많으니 놓치지 말 것

검색 도구는 상황에 맞게 고르세요:
- 먼저 WebSearch로 빠르게 훑어서 후보를 찾는 것이 보통 가장 효율적입니다.
- 목록이 동적으로 로드되거나 검색 결과만으로 부족하면 브라우저 자동화 도구(claude-in-chrome 등)로 직접 플랫폼에 들어가 검색하세요. 이 경우 도구가 지연 로드되어 있을 수 있으니 ToolSearch로 필요한 도구를 한 번에 묶어 불러오세요.
- **로그인이 필요한 페이지는 로그인을 시도하지 마세요.** 비로그인 상태로 볼 수 있는 공개 목록만 수집합니다. 로그인해야 더 많은 공고가 보인다면, 그 사실만 사용자에게 알려주고 넘어가세요.
- 지원서 제출, 회원가입, 폼 입력 등은 이 스킬의 범위가 아닙니다. 정보 수집만 합니다.

### 3단계 — 결과 정리 및 파일 반영

`채용정보_잡코리아.md`의 기존 구조를 그대로 따르세요:

```
### {번호}. [ ] {공고 제목} — {회사명}
- 지역: ...
- 자격요건: ...
- 마감일: ... (수집 시점 기준이라는 점을 인지)
- 출처: 잡코리아 / 원티드 / 사람인 / 게임잡 중 하나
- 링크: ...
- 메모: 마스터 프로필과의 연결점, 우선순위 판단 근거 등
```

분류 기준(A/B/C 섹션)도 기존 그대로 유지하세요:
- **A. 인턴 공고**: 재학생도 지원 가능성 높은 것 — 최우선
- **B. 신입 공고**: 졸업 시점에 맞춰 재확인할 것
- **C. 경력직 공고**: 지금은 지원 불가, 트렌드/요구 스택 참고용

새로 찾은 공고는 번호를 이어서 추가하고, 체크박스는 `[ ]`(미체크) 상태로 둡니다 — 지원 여부 체크는 사용자 몫입니다. 이미 등록된 공고의 마감일이 바뀌었거나 마감되었다면, 항목을 지우지 말고 메모에 "마감됨"으로 갱신하세요 (파일 사용법에 이미 명시된 규칙입니다).

파일 하단 "다음에 확인해볼 것" 섹션도 이번에 새로 알게 된 것(예: 특정 시즌에 공고가 몰리는 패턴, 아직 안 찾아본 플랫폼/키워드)이 있으면 갱신하세요.

### 4단계 — 결과 요약

작업이 끝나면 사용자에게 짧게 요약하세요: 몇 개의 새 공고를 찾았는지, 어느 플랫폼에서 왔는지, 그중 마감이 임박했거나 마스터 프로필과 특히 잘 맞는 것이 있으면 짚어주세요. 검색했지만 못 찾은 플랫폼이나 로그인 때문에 못 본 부분이 있으면 솔직하게 알려주세요 — 없는 공고를 지어내지 않는 것이 이 스킬에서 가장 중요한 원칙입니다.
