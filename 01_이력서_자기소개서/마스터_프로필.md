## 경력/활동 이력

### 게임 UI/UX 취업 준비 (~2025년)
- 작년까지 게임 UI/UX 직무로 취업을 준비하며 포트폴리오 제작
- 최종 취업으로 이어지지는 못함
- 포트폴리오 자료: 보유 중 (다른 곳에 보관 — 정리 시 이 폴더로 이동 예정), Behance에 공개된 포트폴리오는 [링크](#링크) 참고

### 팀 프로젝트: AI 생산성 사이트 (2026년 5~6월)
- 개요: AI를 활용해 게임처럼 즐기는 생산성 사이트 제작
- 팀 구성: 총 6명
- 담당 역할: **팀장** + 프론트엔드, 디자인
- 사용 기술: HTML, CSS 위주
- AI 활용 방식 (2가지):
  1. 개발 보조: AI 코딩 어시스턴트를 활용해 코드 작성 지원
  2. 제품 기능: 학습 내용을 바탕으로 문제를 자동 제작해주는 AI 기능을 사이트 자체에 구현 (AI API 연동)
- 팀장으로서 겪은 어려움과 해결: 기획 방향과 팀원 각자가 원하는 기능을 조율하는 과정이 가장 힘들었음
  - 해결 과정: 미리 잡아둔 기획서를 기준으로 팀원들의 의견을 수렴 → 소외되는 의견 없이 전부 반영 → 그중 MVP를 선별하고 나머지는 부가 기능으로 배치
  - 결과: 전원의 의견을 반영하면서도 우선순위(MVP)가 명확한 프로젝트 구조를 완성

## 차별점 / 강점

- 디자인 고등학교 출신 + 게임 UI/UX 포트폴리오 제작 경험으로, 일반 개발자 대비 디자인 이해도가 높음
- 개발(프론트엔드)과 디자인을 모두 다룰 수 있어 협업 시 커뮤니케이션 및 UI 구현 완성도에서 강점 예상

## 개인 스토리 (자기소개서용)

### 디자인에서 개발로 영역을 넓힌 계기
- 디자인만으로는 한계를 느낌 — 아무리 UI/UX를 잘 그려도 직접 동작하게 만들 수 없다는 답답함
- 개발을 주력으로 하면서 디자인도 할 줄 알면, 스스로 간섭(컨트롤)할 수 있는 범위가 넓어짐
- 궁극적으로 "정말 만들고 싶은 것을 스스로 완결해서 만들고 싶다"는 동기로 개발 영역까지 확장

### 전공(AI게임소프트웨어학과) 선택 이유
- AI와 게임을 접목한 것을 직접 만들어보고 싶어서 이 전공을 선택함
- 게임 개발 자체에 대한 관심에, AI 기술을 결합하는 방향성까지 함께 가져가고 싶어함
- → AI 기술을 다루는 부서/직무(예: 넥슨 AI본부)에 대한 관심과 자연스럽게 연결됨

### 일본 게임업계를 지망하는 이유
- 실무 경험 자체가 필요하다는 실용적 이유 + 취향적 이유 둘 다 있음
- 평소 선호하는 게임 스타일: 패키지/콘솔 게임처럼 하나의 이야기가 세세하고 밀도 있게 구성된 게임을 좋아함
- 일본 게임업계가 이런 스타일(정교한 스토리텔링 중심의 콘솔/패키지 게임)의 비중이 높다고 느낌
- 반면 한국 게임 시장은 모바일 위주로 비슷한 장르가 많다고 느껴, 본인 취향과 맞는 방향은 일본 쪽이라 판단
- → 후쿠오카 게임 인턴십 참여사 중 FromSoftware(정교한 세계관·스토리텔링으로 유명) 등에 특히 관심
