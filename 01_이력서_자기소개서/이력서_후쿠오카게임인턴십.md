## 경력 / 프로젝트

### 게임 UI/UX 포트폴리오 제작 (~2025년)
- 게임 UI/UX 직무를 목표로 다수의 포트폴리오 프로젝트 제작
- Figma 기반 UI 설계 및 프로토타이핑
- Behance에 공개 (상세 링크는 상단 참고)

### 팀 프로젝트: AI 생산성 사이트 (2026년 5~6월)
- **팀장 / 프론트엔드 / 디자인** 담당, 총 6인 팀
- AI를 활용해 게임처럼 즐기는 생산성 사이트 기획 및 제작
- AI 코딩 어시스턴트를 활용한 개발 + 학습 문제를 자동 생성해주는 AI 기능을 제품에 직접 구현 (AI API 연동)
- 기획서를 기준으로 팀원 전원의 의견을 수렴하여 MVP 및 부가 기능을 선별, 우선순위가 명확한 프로젝트 구조 완성

## 강점

- **디자인 × 개발 하이브리드 역량**: 디자인 고등학교 출신 + 게임 UI/UX 포트폴리오 경험으로, 일반 개발자 대비 높은 디자인 이해도를 바탕으로 완성도 높은 UI 구현 가능
- **프로젝트 리딩 경험**: 6인 팀 프로젝트에서 팀장으로서 기획과 팀원 의견을 조율해 MVP를 성공적으로 도출
- **일본 게임업계에 대한 명확한 지향점**: 정교한 스토리텔링 중심의 콘솔/패키지 게임을 선호하며, 이는 일본 게임업계의 강점과 맞닿아 있음
