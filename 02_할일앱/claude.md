# 할일 관리 앱

## 개요
순수 Vanilla JavaScript로 만든 할일 관리 앱입니다. 프레임워크 없이 HTML, CSS, JavaScript를 하나의 파일에 구현했습니다.

## 기술 스택
- **HTML5**: 마크업 구조
- **CSS3**: 반응형 디자인 및 스타일링
- **Vanilla JavaScript**: 모든 로직 구현
- **LocalStorage**: 브라우저 내 데이터 저장

## 주요 기능

### 1. 할일 저장
- 입력 필드에 할일 입력
- "추가" 버튼 클릭 또는 Enter 키로 추가
- 자동으로 LocalStorage에 저장

### 2. 할일 수정
- 각 할일의 "수정" 버튼 클릭
- 모달 창에서 텍스트 수정
- "저장" 버튼으로 변경사항 적용

### 3. 할일 삭제
- 각 할일의 "삭제" 버튼 클릭
- 확인 대화상자 후 삭제
- 즉시 목록에서 제거

### 4. 완료 처리
- 각 할일 왼쪽의 체크박스 클릭
- 완료 상태 토글
- 완료된 할일은 투명도 낮아지고 취소선 표시

## 데이터 구조
```javascript
{
  id: 1234567890,           // 타임스탬프 기반 고유 ID
  text: "할일 텍스트",        // 할일 내용
  completed: false,          // 완료 여부
  createdAt: "ISO 문자열"   // 생성 시간
}
```

## 통계
- **전체**: 총 할일 개수
- **완료**: 완료된 할일 개수

## 보안
- XSS 방지: `escapeHtml()` 함수로 사용자 입력 안전 처리
- 입력 값 검증: 빈 문자열 추가 방지

## 파일 실행
1. `index.html` 파일을 Windows 탐색기에서 찾기
2. 파일을 더블클릭하여 브라우저에서 열기
3. 할일을 추가하고 관리하기

## 브라우저 호환성
- Chrome, Edge, Firefox, Safari 등 최신 브라우저 모두 지원
- LocalStorage 지원하는 모든 현대 브라우저에서 동작
